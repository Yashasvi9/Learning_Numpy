Welcome to Learning_Numpy!

This repository contains my practice code, Jupyter Notebook, and sample data file created while learning NumPy in Python. It documents my learning journey and hands-on practice with NumPy concepts.

📌 About

NumPy (Numerical Python) is a fundamental Python library for numerical computing. It provides powerful tools for working with arrays, mathematical operations, and numerical data.

In this repository, I practice NumPy concepts through examples and exercises to strengthen my understanding and build a strong foundation for Data Science, Data Analysis, and Machine Learning.

📚 Topics Covered

Some of the concepts covered in my practice include:

Introduction to NumPy

Creating NumPy arrays

Array attributes

Array indexing and slicing

Array operations

Mathematical operations

Reshaping arrays

Array dimensions

Iterating over arrays

Random number generation

Basic statistical operations

Reading and working with data from a text file

Other NumPy concepts and functions

This repository will be updated as I continue learning and practicing NumPy.

🚀 How to Use

If you want to explore or run the notebook locally:

1. Clone the repository
git clone https://github.com/<your-username>/Learning_Numpy.git

2. Navigate to the project directory
cd Learning_Numpy

3. Install the required libraries
pip install numpy jupyter

4. Start Jupyter Notebook
jupyter notebook

5. Open the notebook

Open Learning_Numpy.ipynb and run the examples.

Make sure that data.txt remains in the same directory as the notebook if the code reads data from this file.
